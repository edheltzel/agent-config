# AGENTS.md

## Purpose

Implementation plans, requirements, and handoffs for this repo. One plan file is not a DOX boundary.

## Ownership

- Plans and requirements live in `docs/plans/` as dated Markdown.
- Handoffs live in `docs/plans/handoffs/`. That is the handoff location for this repo.
- `docs/solutions/` is not a plan. Its frontmatter contract stays in the root `AGENTS.md`.

## Local Contracts

- A handoff name is timestamped and descriptive. Follow `global/docs/agents/handoffs.md`.
- End a handoff with a `## Todo` section of todo.txt lines, and add those lines to `~/todo.txt` with tuxedo.
- Never write a handoff only to `/tmp`, a harness install directory, or home scratch.
- Report the final path.

## Work Guidance

- Follow `global/docs/agents/handoffs.md` when writing a handoff.
